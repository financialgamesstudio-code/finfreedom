# Фінансова свобода: пакет для Google Play

## Що в архіві
- `index.html`, `manifest.json`, `sw.js`: гра як PWA (працює офлайн після першого відкриття)
- `icons/`: іконки 192, 512 і maskable 512
- `privacy.html`: політика конфіденційності (**підставте свою пошту** замість `ВАША_ПОШТА@example.com`)
- `store/`: п'ять скриншотів 1200x2400 і банер 1024x500 для сторінки в Google Play

## Крок 1. Виставити гру в інтернет (HTTPS)
Найпростіше GitHub Pages:
1. Створіть репозиторій на github.com, завантажте в нього **всі файли з цієї папки** (без папки `store`, вона потрібна лише для Play).
2. Settings → Pages → Branch: main → Save. Через хвилину гра відкриється за адресою `https://ВАШ_НІК.github.io/НАЗВА/`.
3. Перевірте: відкрийте адресу в Chrome на телефоні, у меню має з'явитися «Установити застосунок».
Політика конфіденційності буде за адресою `.../privacy.html`, її посилання знадобиться в Play Console.

## Крок 2. Зібрати .aab
Варіант А (найпростіший): сайт https://www.pwabuilder.com
1. Вставте адресу гри, натисніть Start, потім Package for stores → Android.
2. Заповніть: Package ID, наприклад `ua.yourname.finfreedom`; назва «Фінансова свобода»; версія 1.
3. Залиште прапорець «Google Play: Signing key — створити новий» і **збережіть ключ та паролі** (без них не вдасться оновлювати застосунок).
4. Завантажте архів: у ньому буде `.aab`.

Варіант Б: Bubblewrap (`npm i -g @bubblewrap/cli`, потім `bubblewrap init --manifest https://.../manifest.json` і `bubblewrap build`).

## Крок 3. Digital Asset Links (щоб зникла адресна стрічка)
PWABuilder/Bubblewrap покажуть відбиток ключа (SHA-256). Створіть у репозиторії файл `.well-known/assetlinks.json` з цим відбитком (готовий текст пропонує PWABuilder).
Якщо ви публікуєте через GitHub Pages у підпапці, а не на власному домені, зверніться до довідки PWABuilder: для TWA краще мати домен або `ВАШ_НІК.github.io` як окремий репозиторій.

## Крок 4. Play Console (play.google.com/console)
1. Акаунт розробника: разово $25, підтвердження особи.
2. Створити застосунок: мова українська, тип Застосунок, безкоштовний.
3. Сторінка в магазині:
   - Коротко (до 80 символів): Інвестуйте, відкривайте бізнес і переживайте кризи від 20 до 65 років.
   - Повний опис: гра про гроші від 20 до 65 років: професія, зарплата, інфляція, інвестиції (акції, крипто, нерухомість), бізнеси, ринкові кризи й цілі.
   - Іконка 512: `icons/icon-512.png`; банер: `store/feature-graphic-1024x500.png`; скриншоти: `store/screenshot-*.png`.
4. Політика конфіденційності: посилання на `privacy.html`.
5. Безпека даних: дані не збираються й не передаються. Реклама: немає. Покупки: немає.
6. Рейтинг вмісту: заповніть анкету (без насильства, азартних ігор на гроші чи покупок). Гра симулює інвестування, але не є азартною.
7. Цільова аудиторія: 13+ (або 18+, якщо хочете уникнути додаткових вимог до дитячих застосунків).
8. Завантажте `.aab` у розділ Testing → Closed testing.
   Для нових особистих акаунтів потрібно мінімум 12 тестувальників упродовж 14 днів. Потім можна подати заявку на Production. Актуальні умови перевірте в довідці Play Console.

## Нотатка
Прогрес гри зберігається в браузері застосунку, на кожному телефоні окремо.
